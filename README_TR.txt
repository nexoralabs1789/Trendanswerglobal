TrendAnswer Global — 5 yeni yazı paketi

Bu paket daha önce onaylanan Bedrock yazısını içermez. Mevcut Bedrock yazısını GitHub’da koru.

1. Beş yeni .html dosyasını deponun KÖK dizinine yükle. iPad’de her dosya ayrı seçilebilir.
2. index.html ve sitemap.xml mevcut dosyalarıdır: GitHub’da ilgili dosyayı aç, kalem simgesine bas, bu paketteki aynı adlı dosyanın içeriğiyle TAMAMEN değiştir ve Commit changes yap. GitHub yükleme ekranı mevcut dosyanın üzerine yazmayı destekliyorsa bunu tercih edebilirsin.
3. Yeni HTML dosyalarını doğrudan açıp içeriği kontrol et.
4. Sitemap: https://nexoralabs1789.github.io/Trendanswerglobal/sitemap.xml
5. İçeriklerdeki kaynakları sen de kontrol et; yalnızca insan onayından sonra yayınla.

NOT: ZIP dosyasını olduğu gibi GitHub’a yükleme. İçindeki 7 web dosyasını kök dizinde kullan.
