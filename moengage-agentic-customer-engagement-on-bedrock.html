MoEngage Agentic Customer Engagement on Bedrock

Introduction to MoEngage and Merlin AI

According to the publisher, MoEngage—a customer engagement platform used by more than 1,350 consumer brands—built Merlin AI, a set of artificial intelligence (AI) agents that work with live platform data. Marketing and product teams can draft, analyze, and adjust campaigns from a single conversation. The publisher states that this architecture was built using Amazon Bedrock and Amazon Bedrock AgentCore.

Four Agent Modes in Merlin AI

The source text notes that Merlin AI operates four kinds of agents, all backed by foundation models in Amazon Bedrock for reasoning and generation, the AgentCore runtime for hosting, and the Model Context Protocol (MCP) for standardized data access:

  • Merlin AI Studio: Places purpose-built agents into workflows, including a Copywriter, a Designer, Segment Assist, Jinja Assist, an In-App Template Builder, and Flow Assist .
  • Conversational agents: Operate across campaigns, analytics, segments, and flows. This includes a Campaign Insights Agent embedded on the analytics page that delegates tasks to specialized sub-agents.
  • Custom agents: Allow lifecycle and CRM teams to run continuous agents on MoEngage data and tools under defined rules, offering either full autonomy or required human review.
  • Decisioning agents: Act for individual customers to determine what to say, when, and on which channel, including Offer Decisioning and Campaign Decisioning.

Architecture and Tenant Isolation

MoEngage designed its architecture around four distinct layers: 1. Clients: Internal Merlin AI agents and external MCP clients (such as Claude and ChatGPT via the MoEngage MCP Connector) connect to the MoEngage MCP server. 2. MCP server on AgentCore runtime: Hosts the MCP server to expose MoEngage platform capabilities as MCP tools without running its own model. 3. MoEngage platform APIs: The MCP server calls OpenAPI 3.0-compatible APIs that enforce existing permissions and data residency rules. 4. Foundation models in Amazon Bedrock: Utilized for tool-call planning, content generation, and summarizing results.

To keep multi-tenant data secure and isolated, the publisher notes that the MCP server reuses existing JWT-based authentication, workspace and user contexts travel in request headers rather than tool arguments, and the AgentCore runtime executes each user session in an isolated environment. Additionally, Amazon Bedrock Guardrails apply content safety and PII filters.

Customer Results

According to the publisher, MoEngage customers have realized operational improvements using these tools. For example, the customer Glance achieved a 38% uplift in push notification click-through rates and reached campaign go-live 50% faster.
